Sobre o Projeto 01

Este é o segundo nível do laboratório de estudos de cibersegurança, evoluindo a partir do Projeto00. Algumas falhas óbvias foram "corrigidas" na aparência, mas novas vulnerabilidades propositais foram introduzidas para estudo.

Senhas são guardadas com hash MD5 sem salt, a sessão do usuário é um JWT que nunca expira guardado no localStorage, o filtro de busca do Kanban está vulnerável a SQL Injection, e a aba "Usuários" (visível só para quem é admin) é alimentada por uma rota que não confere papel nenhum no backend.

Aviso: este projeto tem fins exclusivamente educacionais e não deve ser usado como referência de implementação em produção.
