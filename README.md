# ProjetoSeguranca

Repositório de estudos de cibersegurança. Aqui serão criados múltiplos projetos independentes, cada um explorando um nível de segurança diferente (do vulnerável de propósito ao hardened), para praticar identificação e correção de vulnerabilidades em aplicações reais.

## Objetivo

- Estudar conceitos de segurança ofensiva e defensiva através de projetos práticos.
- Comparar implementações inseguras e seguras de um mesmo problema.
- Servir como laboratório pessoal (CTF-like) para testar técnicas de exploração e mitigação.

## Stack

- **Frontend**: Angular + TypeScript
- **Backend**: Django + Python

## Estrutura

Cada projeto vive em seu próprio diretório na raiz do repositório, com um README próprio descrevendo o nível de segurança abordado, as vulnerabilidades propositais (quando houver) e como executá-lo.

## Aviso

Os projetos aqui contidos têm finalidade exclusivamente educacional. Vulnerabilidades introduzidas intencionalmente não devem ser replicadas em ambientes de produção.
